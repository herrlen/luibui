# URL design

Marketing skills often explain wording, joins and fragments of text. Those are advice, not an
instruction to the model.

1. **Short and readable.** `/pricing` beats `/index.php?page=42`.
2. **Hyphens, not underscores.** Google treats hyphens as word separators. Underscores join words.
   `/seo-tips` not `/seo_tips`.
3. **Lowercase only.** `/About-Us` and `/about-us` can count as two pages.
4. **Combine the parts of a title** in a fixed order: page topic first, then the brand, e.g.
   "Pricing – Example Shop".
5. The first part of the path is the section, the second part is the page:
   `/blog/url-design`.

When in doubt, ask for the site's existing URL scheme before suggesting changes.
